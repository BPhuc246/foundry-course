1. Open bash and paste this: `curl -L https://foundry.paradigm.xyz | bash`
2. Run from source given or open and run from other terminal
3. Paste and run `foundryup` --> Install forge, anvil, cast, chisel
4. Initialize foundry: 
    - Method 1:
        + Create folder and navigate to that folder: `mkdir <my-foundry-project> cd <my-foundry-project>`
        + Init: `forge init`
    - Method 2:
        + Force init in the folder you staying: `forge init --force`
